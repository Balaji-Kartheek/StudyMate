# StudyMate
StudyMate


`django-admin startproject studymate` -> To setup the Project


`python manage.py runserver` -> To Execute the Project

`localhost/admin` -> To run the admin server

`python python.py makemigrations`  -> [Commit] Make Migrations for the Updated Models

`python manage.py migrate` ->[Push] To Push the Migrations

`admin.site.register(<modelName>)` -> To register the Model into the Admin Page
